SCENTLINE - GitHub Pages
1. Create a GitHub repo, upload index.html and .nojekyll to the main branch (root).
2. Settings > Pages > Source: "Deploy from a branch", branch main, folder / (root).
3. Open https://YOUR-NAME.github.io/REPO-NAME/ . Share that link: everyone who opens it joins the same world.
Online uses peer-to-peer connections found through public relays, so it needs internet and may fail on some strict school/work networks.
